## 1. Canonical identity

### Core carrier

At minimal framework scope, the configuration class is **causal sets themselves, modulo the appropriate representational redundancy**. A causal set is a locally finite causal order `(C, ≺)` under the declared FCP-9 source convention.

Core mathematical/physical commitments are:

- elementary discrete causal-set elements;
- a causal/order relation `≺` satisfying the source convention's order/acyclicity conditions;
- local finiteness;
- order interpreted physically as proto-causal structure;
- local finiteness/cardinality interpreted as fundamental discreteness, with number supplying volume information in continuum approximation.

Permanent control:

> **CAUSAL ORDER + LOCAL FINITENESS != CONTINUUM SPACETIME.**

A bare generic poset without the CST physical interpretation and continuum program is not, by that fact alone, `FW-CST`.

### Core dynamics

**None.** Minimal `FW-CST` is kinematic. No sequential-growth law, quantum measure, path sum, action choice, field assignment, or phenomenological model is primitive to the canonical core.

### Physical-state identity

The core physical configuration is the causal set, not:

- one labelled birth ordering;
- one sequential-growth history;
- one continuum embedding;
- one Poisson sprinkling prescription;
- one quantum measure/decoherence functional;
- one action or transition rule;
- one scalar or other matter-field assignment.

Those structures belong to representation, realization, or extension layers.

## 2. Representation and equivalence

Kinematic equivalence is governed by order isomorphism/relabeling redundancy: labels do not create distinct causal-set structure.

This is distinct from **dynamics covariance**. Discrete general covariance and related covariance constraints enter particular growth/dynamics constructions; they are not added to the minimal `C0` definition merely because they are important in CSG/QSG.

A continuum embedding is likewise not itself the physical configuration and does not define a new equivalence class by fiat.
