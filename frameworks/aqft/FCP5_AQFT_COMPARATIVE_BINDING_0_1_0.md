## 0. Purpose

This file freezes the exact AQFT object admitted to FCP-5 before K1–K10 relationship classification. It adds no new AQFT subtradition beyond FCP-4.

The comparison asks which AQFT structures are:

- `REFORMULATION` — same physical content organized differently;
- `STRUCTURAL_REFINEMENT` — sharper organization/theorems without independent empirical content;
- `MODEL_CLASS_EXTENSION` — materially broader framework/model organization;
- `PHYSICAL_EXTENSION` — additional physically interpreted structure;
- `EMPIRICALLY_DISTINCT` — source-bound discriminator relative to the null QFT baseline;
- `OPEN` — source scope does not decide.

These descriptors do not replace FCP primary claim classifications.

## 5. Relationship rule

Because AQFT is historically and mathematically a reformulation/extension lineage of QFT, structural agreement with ordinary QFT is not automatically `INDEPENDENT_CONVERGENCE`.

FCP-5 uses:

- `REFORMULATION_RELATION` when the AQFT structure represents or reorganizes the same physical content;
- `INDEPENDENT_CONVERGENCE` only if genuinely independent derivational histories and the frozen FCP convergence rules justify that stronger description.

At this source scope, no AQFT–null relation is presumed to be independent convergence.

## 6. Empirical inheritance rule

Concrete masses, couplings, decay rates, cross sections, spectra and Standard Model numerical fits are therefore not independent evidence selecting abstract AQFT unless a distinct AQFT prediction is source-bound.
