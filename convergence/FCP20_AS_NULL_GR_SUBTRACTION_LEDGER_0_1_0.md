# FCP-20 — AS / Null-GR Subtraction Ledger

**Version:** 0.1.0  
**Status:** SUBTRACTION-LEDGER CANDIDATE  
**Frameworks:** `FW-AS`, `FW-NULL-GRQFTSM`

## 0. Purpose

This ledger performs the ordered subtraction required before any Asymptotic Safety structure can be carried forward as independent foundational content.

Ordered filter:

`RAW_AS_STRUCTURE`
→ `GENERIC_MATH/RG_SUBTRACTION`
→ `QFT/RG_LINEAGE_SUBTRACTION`
→ `GR_LINEAGE/TARGET_SUBTRACTION`
→ `MODEL/TRUNCATION_SUBTRACTION`
→ `OPTIONAL/PHENOMENOLOGY_SUBTRACTION`
→ `EMPIRICAL_INHERITANCE_SUBTRACTION`
→ `SURVIVING_AS_SPECIFIC_RESIDUE_OR_NONE`.

The goal is neither to erase valid AS science nor to retain every structure absent from the null baseline.

## 1. S0 — generic mathematics / RG shell

Subtract as independent convergence credit:

- generic theory-space language;
- generic action/effective-action machinery;
- beta functions as mathematics;
- fixed-point linearization as generic dynamical-systems/RG machinery;
- generic relevant/irrelevant eigendirections;
- generic quotient/gauge-redundancy reasoning;
- generic correlation functions and vertices;
- generic continuum-limit and coarse-graining language.

These may remain scientifically necessary, but they do not identify AS-specific foundational content.

## 2. S1 — QFT/RG lineage

Subtract as independent rediscovery:

- Wilsonian/renormalization-group methodology;
- running couplings;
- effective field theory/matching ideas;
- effective-average-action/functional-flow machinery at the level that is standard QFT/RG method;
- ordinary QFT observable/correlation formalism;
- regulator/scheme choice as calculational structure.

The formal FRG equation can be exact while a projected gravitational solution remains approximate. The inherited formal method is not itself the AS hypothesis.

## 3. S2 — GR lineage and supplied target

Subtract as independent convergence credit:

- classical metric variables supplied from GR where used;
- Einstein-Hilbert structures used as truncation content or infrared target;
- diffeomorphism structure inherited from metric gravity;
- Lorentzian causal structure when supplied as the physical target;
- GR-like low-energy dynamics used as a desired recovery condition;
- measured Newton/cosmological parameters used for trajectory calibration.

A real relation may survive as lineage or target-conditioned reconstruction without becoming independent convergence.

## 4. S3 — model/truncation dependence

Do not promote to whole-framework necessity:

- a fixed point in one truncation;
- one regulator/gauge/field parametrization result;
- one relevant-direction count;
- one background/dynamical coupling choice;
- one matter-content bound;
- one selected UV→IR trajectory;
- one Lorentzian truncation.

Multi-truncation persistence is retained as stronger evidence than a single truncation but still does not become an exact complete-theory theorem.

## 5. S4 — optional extensions / phenomenology

Remove from base-framework residue unless unavoidable:

- RG-improved black-hole prescriptions;
- optional cosmological/inflationary models;
- trajectory-specific scale/hierarchy phenomenology;
- model-specific matter restrictions;
- optional particle-physics extensions;
- detector proposals that require additional scale-identification or phenomenological assumptions.

Lorentzian realization work is not erased as optional phenomenology; it remains a base physical-realization burden under `AS-PHYS`.

## 6. S5 — empirical inheritance

Subtract as independent AS empirical credit:

- successful GR tests reproduced in an IR GR-like regime;
- successful QFT/SM predictions recovered after matching;
- observed parameters inserted to select/calibrate a trajectory;
- compatibility with established particle content;
- phenomenological fits not compelled by base AS.

`FCP20_INDEPENDENT_AS_E4 = 0`.

## 7. Candidate residue-by-residue audit

### AS-R1 — interacting gravitational UV fixed-point hypothesis

**Raw content:** the physically relevant gravitational RG flow possesses an appropriate interacting/non-Gaussian UV fixed point.

**S0:** generic fixed-point mathematics subtracts, but the claim that *gravity's physical UV completion* is governed by such a fixed point is not generic mathematics.

**S1:** RG machinery subtracts; the gravitational physical fixed-point commitment does not.

**S2:** GR supplies the low-energy gravitational arena but does not itself posit this UV fixed point.

**S3:** individual truncation fixed points subtract as framework necessity; the framework hypothesis remains, with evidence ceiling recorded separately.

**S4:** independent of optional cosmology/black-hole phenomenology.

**S5:** no empirical inheritance needed to state the commitment.

**Disposition:** `SURVIVES_AS_AS_SPECIFIC_RESIDUE`.

**Status:** framework hypothesis with AS-L3 evidence; complete-theory existence theorem absent.

### AS-R2 — finite-dimensional UV critical surface / relevant-parameter architecture

**Raw content:** the physical fixed point has a finite-dimensional UV critical surface, so only finitely many relevant parameters specify UV-complete trajectories.

**S0:** linearized eigendirection mathematics is generic; the physical finite-critical-surface requirement is AS-specific.

**S1:** RG critical-surface machinery subtracts as method, but the physical predictivity architecture remains framework-specific.

**S2:** GR/null does not supply a corresponding UV critical surface.

**S3:** numerical two/three-direction counts are truncation dependent and are removed from exact framework-level content.

**S4/S5:** no optional phenomenology or inherited empirical success is required for the formal commitment.

**Disposition:** `SURVIVES_AS_AS_SPECIFIC_RESIDUE`.

**Ceiling:** exact physical critical-surface dimension remains `OPEN`; complete predictivity theorem remains `OPEN`.

### AS-R3 — multi-truncation robustness evidence

**Raw content:** interacting gravitational fixed points recur across diverse finite truncations/operator bases with nontrivial scheme/truncation robustness studies.

**S0/S1:** generic use of truncations and RG subtracts; the recurring gravitational fixed-point evidence itself is not generic.

**S2:** it is evidence about the proposed UV completion, not a restatement of classical GR.

**S3:** individual coordinates/relevant-direction counts do not survive as exact; the cross-truncation persistence pattern does.

**S4/S5:** independent of optional phenomenology and recovered GR empirical success.

**Disposition:** `SURVIVES_AS_EVIDENCE_RESIDUE`.

**Ceiling:** `AS-L3_MULTI_TRUNCATION_ROBUSTNESS`, not complete-theory proof.

### AS-R4 — fixed-point-defined continuum / UV→IR trajectory program

**Raw content:** a continuum UV completion is specified by fixed-point control and trajectories on the UV critical surface, with selected trajectories extending toward physical infrared regimes.

**S0/S1:** continuum/RG trajectory language is generic and QFT lineage; remove that shell.

**S2:** the GR-like infrared endpoint is target-conditioned and receives no independent convergence credit.

**S3:** particular trajectories/truncations do not become framework-unique.

**S4/S5:** optional phenomenology and inherited low-energy success are removed.

**Surviving content:** the AS-specific requirement that a physically acceptable complete trajectory emanate from/interpolate with the interacting UV fixed-point critical surface.

**Disposition:** `SURVIVES_AS_AS_SPECIFIC_RESIDUE_WITH_TARGET_CONDITIONED_ENDPOINT`.

**Ceiling:** complete realistic global trajectory remains open; pairwise E3 not source-qualified at the current packet.

### AS-R5 — Lorentzian and gravity–matter fixed-point realization program

**Raw content:** source-bound Lorentzian/foliated fixed-point work and gravity–matter fixed-point studies extend the AS hypothesis beyond Euclidean pure-gravity truncations.

**S0/S1:** generic QFT/matter/Lorentzian methods subtract.

**S2:** compatibility with Lorentzian GR and observed matter is partly target-conditioned.

**S3:** quantitative conclusions remain implementation/truncation dependent; contrasting matter studies are retained as tension rather than averaged.

**S4:** optional phenomenology subtracts; Lorentzian realization itself remains a base-framework burden.

**S5:** Standard-Model/GR success is not inherited as AS evidence.

**Disposition:** `SURVIVES_AS_PARTIAL_REALIZATION_RESIDUE`.

**Ceiling:** substantive but incomplete; complete Lorentzian unitarity/causal observables and unique realistic gravity–matter trajectory remain open.

### AS-R6 — physical trajectory / calibration / empirical-selection burden

**Raw content:** AS must select a physically realistic UV-complete trajectory, map it to Lorentzian observables and determine which low-energy parameters are predictions rather than fitted inputs.

**S0/S1:** generic calibration and trajectory concepts subtract.

**S2:** GR/QFT target data cannot count as independent AS evidence.

**S3/S4:** particular trajectories and phenomenology do not bind the framework.

**S5:** inherited empirical success is removed completely.

**Disposition:** `SURVIVES_AS_OPEN_SELECTION_BURDEN`.

**Ceiling:** no unavoidable base-framework discriminator at current scope.

## 8. Structures removed completely from independent AS residue
