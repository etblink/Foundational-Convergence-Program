**Version:** 0.1.0

**Status:** OPTIONAL-STRUCTURE / SCOPE LEDGER CANDIDATE

## 0. Purpose

This ledger prevents source-qualified CQM extensions from being silently aggregated into one maximal framework and records which structures remain worth carrying after the null/QM and generic-mathematics subtraction.

Minimal core remains only the process/category shell bound by FCP-4.

## 1. Dagger structure

- `minimal_core`: **NO**
- `source_scope`: AC-2004/2009 and CK-2017 quantum categorical development where explicitly assumed
- `quantum_role`: adjoint-like operation, dagger-compatible process equations and quantum structural reasoning
- `null/QM relation`: corresponds to adjoint structure in appropriate Hilbert-space models
- `strongest relation`: bounded `E2_FUNCTORIAL_REPRESENTATION` at named model scope
- `primary classification`: `EXTENSION_DEPENDENT / STRUCTURAL_REFINEMENT`
- `uniqueness`: **NO** — dagger structure does not uniquely select ordinary QM
- `physical bridge`: model-dependent
- `empirical status`: inherited/none independently
- `carry_forward`: **YES**, only with optional flag
