## 0. Reading rule

This matrix summarizes the strongest source-qualified relation available at each key in each completed pairwise phase through FCP-17.

Codes:

- `Q2` — bounded qualified E2 subrelation exists;
- `Q3` — bounded qualified E3 subrelation exists;
- `I4` — E4/empirical equivalence exists only through a shared or inherited concrete model, with no independent framework-level E4;
- `E5` — strongest positive pairwise relation is E5;
- `NONE` — no positive pairwise relation at framework scope.

A star marks a bounded subrelation whose framework-wide key remains weaker or open. No code is a score.
