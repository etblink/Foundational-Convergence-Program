## 8. Frozen redundancy test

A proposition is `FULLY_REDUNDANT` only if one or more predeclared admitted comparators already establish the materially same proposition at:

```text
EQUAL_OR_HIGHER_AUTHORITY
AND
EQUAL_OR_BROADER_RELEVANT_SCOPE
AND
WITH_NO_WEAKER_CAVEAT_PROFILE
AND
WITH_NO_MATERIAL_LOSS_OF_PRIMARY_OR_CRITICAL_EVIDENCE
```

Topic similarity is insufficient. A review does not automatically render a primary proof, construction, conjecture source, limitation source, or empirical record redundant. A primary paper is not automatically nonredundant if another primary or authoritative source already carries the same material proposition with adequate scope and caveats.
