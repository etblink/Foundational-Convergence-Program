# FCP Method 0.2.1 — Framework-Admission Law-Architecture Revision

**Method version:** `0.2.1`  
**Status:** FROZEN_PROSPECTIVE_METHOD_REVISION_BEFORE_AFFECTED_ADJUDICATION  
**Scope:** framework-admission criterion C only; all other Method 0.2.0 rules remain inherited unless explicitly stated here.

## 1. Trigger

This revision is opened under the Method 0.2.0 `METHOD_REVIEW` trigger because the existing A–H framework-admission architecture fails a framework-neutral invariance test.

The pre-revision criterion was:

```text
C_OLD = INTRINSIC_DYNAMICS_OR_SOURCE_BOUND_FRAMEWORK_LEVEL_DYNAMICAL_ARCHITECTURE
```

When treated as a mandatory `PASS` condition for framework admission, that criterion conflicts with an already-canonical FCP framework identity established before the current causal-process / ICO corpus was adjudicated.

Canonical `FW-CST` was admitted by FCP-10 while its current Framework Register explicitly records:

```text
FW_CST_CORE_DYNAMICS = NONE
CSG = OPTIONAL_C2_CLASSICAL_DYNAMICS_EXTENSION
QSG = OPTIONAL_OR_PROVISIONAL_C3_QUANTUM_DYNAMICS_LAYER
```

The same canonical record identifies the source-bound framework core through locally finite causal order, primitive causal interpretation, fundamental discreteness/local finiteness, and continuum-realization burden.

Therefore:

```text
INVARIANCE_TEST = FAIL_FOR_C_OLD_AS_MANDATORY_FRAMEWORKHOOD_CONDITION
FRAMEWORK_NEUTRAL_COUNTEREXAMPLE = FW-CST
COUNTEREXAMPLE_PREDATES_CURRENT_CAUSAL_PROCESS_STAGE2 = YES
RESULT_DIRECTION_DEPENDENCE = NONE_REQUIRED
```

This is not evidence that every kinematic, constraint-based, or process formalism is a foundational framework. It establishes only that **mature intrinsic dynamics cannot be a necessary condition of framework identity** without contradicting FCP's own framework taxonomy.

## 2. Prospective replacement criterion

Criterion C is prospectively replaced by:

```text
C_NEW = SOURCE_BOUND_PHYSICAL_LAW_CONSTRAINT_OR_DYNAMICAL_ARCHITECTURE
```

`C_NEW = PASS` requires a nontrivial source-bound physical architecture that constrains, selects, structures, or governs admissible physical configurations, processes, histories, transformations, or evolution at the candidate-object level.

The qualifying architecture may be:

```text
KINEMATIC_OR_STRUCTURAL_PHYSICAL_LAW
CONSTRAINT_ARCHITECTURE
PROCESS_OR_HISTORY_CONSTRAINT
DYNAMICAL_LAW
EVOLUTION_OR_TRANSFORMATION_LAW
COMBINATION_OF_THE_ABOVE
```

It may not be satisfied by generic or purely representational structure alone:

```text
BARE_CATEGORY_THEORY = INSUFFICIENT
BARE_LINEAR_ALGEBRA = INSUFFICIENT
BARE_COMPOSITION = INSUFFICIENT
BARE_FUNCTORIALITY = INSUFFICIENT
BARE_GRAPHICAL_CALCULUS = INSUFFICIENT
BARE_SET_OF_ALLOWED_MAPS_WITH_NO_PHYSICAL_LAW_CONTENT = INSUFFICIENT
RESOURCE_LABELING_ALONE = INSUFFICIENT
IMPLEMENTATION_CONTROL_STRUCTURE_ALONE = INSUFFICIENT
```

The controlling question becomes:

> Does the source-bound object contain a physically interpreted law/constraint architecture that is part of what the object says the physical possibilities are, rather than merely a language for representing possibilities supplied by another theory?

## 3. Dynamics maturity becomes a separate characterization

Dynamics remains scientifically important, but it is no longer a binary constitutive gate for framework identity.

Every admitted or serious framework-candidate object must separately report:

```text
DYNAMICS_MATURITY =
INTRINSIC_FRAMEWORK_DYNAMICS
| CONSTRAINT_OR_KINEMATIC_CORE_WITH_OPTIONAL_DYNAMICS
| OPTIONAL_MODEL_FAMILY_DYNAMICS
| PROVISIONAL_DYNAMICS
| NO_INTRINSIC_DYNAMICS_ESTABLISHED
| NOT_APPLICABLE
| UNRESOLVED
```

A framework with `NO_INTRINSIC_DYNAMICS_ESTABLISHED` may still pass framework admission if `C_NEW` is independently satisfied by a source-bound physical law or constraint architecture and all other required admission burdens pass.

Conversely, the existence of transformation rules or a dynamics paper does not by itself make `C_NEW = PASS` if those transformations act only on a representation without supplying candidate-object-level physical law content.

## 4. No relaxation of other admission burdens

The remaining A–H architecture is unchanged except for criterion C:

```text
A = SOURCE_BOUND_PRIMITIVE_COMMITMENTS_OR_PHYSICAL_OBJECT_CLASS
B = COHERENT_STATE_PROCESS_CONFIGURATION_OR_MODEL_DOMAIN
C = SOURCE_BOUND_PHYSICAL_LAW_CONSTRAINT_OR_DYNAMICAL_ARCHITECTURE
D = STABLE_PHYSICAL_SCOPE_AND_DECLARED_MODEL_CLASS
E = SOURCE_BOUND_MEASUREMENT_REALIZATION_OR_PHYSICAL_INTERPRETATION_BURDEN
F = CROSS_SOURCE_CONTINUITY_SUFFICIENT_FOR_OBJECT_SPECIFIC_K1_K10
G = PRINCIPLED_DISTINCTION_FROM_EXISTING_FCP_FRAMEWORKS_AND_GENERIC_MATHEMATICAL_REPRESENTATIONAL_OR_METHOD_TOOLING
H = EXPLICIT_EMPIRICAL_OR_OBSERVATIONAL_BURDEN
```

```text
DISTINCTNESS != ADMISSION
MODEL_COHERENCE != ADMISSION
MATHEMATICAL_UNITY != PHYSICAL_UNITY
EMPIRICAL_IMPLEMENTATION != FRAMEWORK_IDENTITY
LAW_OR_CONSTRAINT_ARCHITECTURE != EMPIRICAL_SUCCESS
```

No scalar aggregation is introduced.

## 5. Symmetric application rule

The revision is framework-neutral and must be available symmetrically to all future framework-taxonomy operations.

It may increase, decrease, or leave unchanged the admission prospects of a candidate depending on whether its apparent structure is genuinely physical-law content or merely representational/admissibility tooling.

```text
PROCESS_MATRIX_SPECIFIC_EXCEPTION = NO
CAUSAL_PROCESS_SPECIFIC_EXCEPTION = NO
FW_CST_RETROACTIVE_RESCORING = NO
OTHER_HISTORICAL_FRAMEWORK_RESCORING = NO
```

Historical results remain historical. This revision governs prospective adjudication only unless a later separately selected reanalysis is justified.

## 6. Why this revision is not result-directed

The revision is justified by a pre-existing canonical counterexample rather than by the desired disposition of the current causal-process corpus.

The relevant facts are independent of the current Stage-2 result:

1. FCP-10 admitted `FW-CST` as a source-bound foundational comparator.
2. Its canonical core explicitly has no intrinsic dynamics.
3. Dynamics appears only in optional/provisional layers.
4. A mandatory-dynamics admission criterion would therefore make the admission rule non-invariant across FCP's own accepted framework set.

The repair would be required even if the current causal-process corpus contained no process matrices, no quantum switch evidence, and no candidate new framework.

```text
FRAMEWORK_NEUTRAL_DEFECT = YES
PREEXISTING_COUNTEREXAMPLE = YES
POST_EXPOSURE_BENEFICIARY_KNOWN = IRRELEVANT_TO_JUSTIFICATION
RULE_TEXT_FROZEN_BEFORE_REVISED_GATE_APPLICATION = YES
```
