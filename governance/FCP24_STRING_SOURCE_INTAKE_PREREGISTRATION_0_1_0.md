## 1. Purpose

FCP-24 is selected as a source-intake phase for the admitted but unaudited historical umbrella `FW-STRING`. Its purpose is to determine, from a bounded source corpus, whether the umbrella defines one coherent source-bound framework, one framework with persistent internal labels, a required framework split, or an umbrella too broad for a stable source-bound object at the declared scope; then to populate a K1–K10 baseline for the resolved object or objects.

This preregistration opens and freezes the later intake method only. It performs no external source search, no taxonomy adjudication, no K1–K10 scoring, no cross-framework comparison, and no convergence assessment.

## 20. Two-stage substantive execution architecture

```text

```

Stage 1 may perform bounded external source discovery, construct the source intake/evidence material, and freeze the adjudicative corpus. It must commit the frozen source state before final taxonomy/K1–K10 adjudication.

### Stage 2

```text
FCP24_STAGE2 = TAXONOMY_AND_K1_K10_FINAL_ADJUDICATION
```

Stage 2 uses only the frozen Stage-1 corpus. No new source discovery is allowed. It may finalize taxonomy, K1–K10, bounded realization/phenomenology status, required live-register updates, and the handoff.

This ordering prevents the final taxonomy from being used to retrofit the source corpus.
