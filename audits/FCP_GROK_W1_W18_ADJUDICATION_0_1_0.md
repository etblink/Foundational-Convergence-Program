## 5. Root-cause compression

W1–W18 reduce to seven underlying issues:

1. early NFC conditioning without true blinding;
2. closed-packet provenance rigidity plus inconsistent E2/E3 application;
3. an independence definition that hides positive target-conditioned viability;
4. a null baseline serving simultaneously as incumbent, recovery target and empirical benchmark;
5. over-compressed genericity terminology;
6. intentionally narrow source packets later carrying broader interpretive weight;
7. insufficient empirical/no-go priority relative to formal pairwise comparison.
