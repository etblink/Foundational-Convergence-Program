## 4. Manuscript theorem and proof adjudication

### Exact accepted theorem

On the gauge-invariant subspace of `L²(R²⁷; F)`, with the relative SU(2) coordinates, Clifford module, real symmetric gamma matrices, and supercharges specified in (1.1), close the nonnegative form

`q(Ψ) = (1/16) Σα ||Qα Ψ||²`

initially defined on the invariant compactly supported smooth core. Let `H` be its associated self-adjoint operator. Then `H` has an orthonormal sequence of square-integrable eigenvectors with positive eigenvalues tending to infinity.

This is a theorem about the defined form operator. It is not a theorem about an unspecified extension of a formal differential expression. Closability and density are addressed before the operator is defined.

### Load-bearing steps

| Step | Independent assessment |
|---|---|
| Dense gauge-invariant core; closable supercharge column | Gauge averaging gives density. Symmetry tests each putative limit of the supercharges against the dense core and makes it vanish. No closability assumption is silently substituted. |
| Lemma 2.1 | The kinetic coefficient is 1/2, the scalar quartic term is nonnegative, and the fermionic coefficient is **i/2** in the rendered PDF. Clifford anticommutation cancels nonscalar pieces of the quadratic terms. The remaining multiplication term is Hermitian and bounded in norm by `C|x|` for some finite C. |
| Lemma 2.2 | The lifted Spin(9) action preserves the form and commutes with gauge symmetry. Isotypic projection preserves the smooth core and is bounded in form norm. Resolvent commutation establishes reduction and the restricted operator's domain correspondence. |
| Lemma 3.1 | The character argument gives `ν1 ≥ λ2` for the Spin(8) stabilizer types. The indicator determinant requires four distinct nonzero initial-row lengths. The integral difference of the allowed weight lattices converts `ν1 > λ2 - 1` to the required bound. The half-integral and `t4 = 0` cases are not excluded. |
| Lemma 3.2 | Restriction at fixed slice parameters is applied to the finite-dimensional translate span of a smooth vector, not to an arbitrary L² equivalence class. Continuity makes the restriction well-defined; stabilizer equivariance carries the branching bound to the slice. |
| Lemma 3.3 | The sixteen-dimensional oscillator `-Δ/4 + r²|z|²` has energy `r(n+8)`. Its polynomial levels contribute first-coordinate weight at most n; finite-dimensional F contributes at most M. Thus `λ2 > m+M` removes levels 0 through m and yields `r(m+9)`. |

No new source or theorem of comparable strength was needed to complete this audit. Standard closed-form representation, compact-group representation theory/Weyl characters, oscillator decomposition, Rellich compactness, and compact-resolvent spectral theory remain ordinary trusted mathematical dependencies. This is an informal proof audit, not a kernel-checked formalization.

### Spectrum and scope controls

The proof establishes positive **point spectrum** and compact resolvent in selected reducing sectors. It does not establish compact resolvent for the whole physical Hilbert space, an essential-spectrum classification, spectral simplicity, or a zero-energy state. If a compatible operator has essential spectrum covering these energies, point eigenvalues can be embedded; the theorem itself does not prove that antecedent.

Neither arbitrary N nor an N-dependent limiting theorem is supplied. In particular, no large-N eigenvalue scaling or survival statement follows from the N=2 result.

## Appendix A. Reproducible finite-algebra verification candidate

This code is an independently derived check of finite identities in the frozen manuscript. It uses NumPy integer matrices of size 16, with bounded small intermediate values; no floating-point tolerance is used. It does not construct the full fermionic module or prove Theorem 1.1.

Save the following as a Python script and run with Python and NumPy. It passed in the adjudication environment.

```python
from itertools import combinations
import numpy as np

# Use J = iY, an integer real matrix. Every selected word has zero or
# two Y factors, so restoring Y contributes the exact sign (-1)^(nY/2).
P = {
    'I': np.eye(2, dtype=np.int64),
    'X': np.array([[0, 1], [1, 0]], dtype=np.int64),
    'Y': np.array([[0, 1], [-1, 0]], dtype=np.int64),
    'Z': np.diag(np.array([1, -1], dtype=np.int64)),
}
WORDS = ['IIIX', 'IIIZ', 'ZZYY', 'XZYY', 'YXXY',
         'YXZY', 'IYIY', 'YZIY', 'IXYY']
G = []
for word in WORDS:
    g = np.ones((1, 1), dtype=np.int64)
    for letter in word:
        g = np.kron(g, P[letter])
    G.append((-1)**(word.count('Y')//2) * g)
I = np.eye(16, dtype=np.int64)
Z = np.zeros((16, 16), dtype=np.int64)
for i, g in enumerate(G):
    assert np.array_equal(g.T, g)
    for j, h in enumerate(G):
        assert np.array_equal(g@h + h@g, 2*I if i == j else Z)
        assert np.trace(g.T@h) == (16 if i == j else 0)
pairs = list(combinations(range(9), 2))
V = {(j, k): G[j]@G[k] for j, k in pairs}
for pair, v in V.items():
    assert np.array_equal(v.T, -v)
    for other, w in V.items():
        assert np.trace(v.T@w) == (16 if pair == other else 0)
    for g in G:
        assert np.trace(g.T@v) == 0
# Dividing the coefficient of f_cab*x_l^b in the derivative contraction
# by f_cab leaves this sum. In dimension nine its value is 8*gamma_l.
for l in range(9):
    result = Z.copy()
    for j, k in pairs:
        if k == l:
            result += G[j]@V[j, k]
        if j == l:
            result -= G[k]@V[j, k]
    assert np.array_equal(result, 8*G[l])
print('real_symmetric_Cl9: PASS (integer arithmetic)')
print('transpose_vector_and_bivector_traces: PASS (integer arithmetic)')
print('cross_derivative_contraction: PASS (8 gamma_l; B coefficient i/2)')
print('scope: finite gamma identities only; not Theorem 1.1 or a Lean proof')

```
