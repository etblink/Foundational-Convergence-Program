## 4. Adjudication rule

For a target to reach framework scope, both of the following must hold:

```text
FORCED_FRAMEWORK_COMMITMENT = YES
NO_CORE_PRESERVING_ESCAPE = ESTABLISHED
```

The decisive distinction is between an abstract burden that belongs to a framework and the additional assumptions of the actual test. A framework may be forced to provide a manifoldlike continuum or a physically consistent UV completion while remaining free to choose among dynamics, measures, gauges, parametrizations, trajectories and exact nonperturbative realizations. A test reaches framework scope only if its adverse premise covers all such core-preserving choices.
